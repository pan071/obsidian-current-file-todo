# 在侧边栏汇总笔记与目录中的 TODO

# 1、功能概览

- 在右侧边栏展示当前打开笔记中的所有 TODO，点击任意一条即可跳转到对应行。
- 支持切换为目录范围，汇总当前笔记所在目录（可含子目录）下所有笔记的 TODO，适合大文档拆分为多篇小文档后统一查看。
- 支持锁定某个目录、按关键词过滤 TODO。
- 识别 Markdown 标准任务、TODO 关键字、`#todo` 标签三类写法，支持代码块内的注释形式。
- 支持平铺列表与按标题分组两种展示模式，分组模式支持嵌套标题树与单层标题路径。
- 只读展示，不会修改笔记内容。
- 支持桌面端与移动端。

# 2、入口

- **右侧边栏标签栏：** 与大纲、标签、反向链接等视图并列的 TODO 图标；首次启用时自动添加，之后由 Obsidian 布局保存。
- **左侧功能区：** 「查看当前文件 TODO」图标，点击打开或聚焦视图。
- **命令面板：**
    - 「显示当前文件 TODO」：打开或聚焦视图。
    - 「显示当前目录 TODO」：切换为目录范围并解除锁定，跟随当前笔记所在目录。
    - 两个命令都可在「设置 → 快捷键」中绑定快捷键。
- **文件列表右键菜单：**
    - 右键目录：「查看该目录 TODO」，切换为目录范围并锁定该目录。
    - 右键笔记：「查看所在目录 TODO」，切换为目录范围并锁定该笔记所在的目录。

# 3、识别规则

- **Markdown 任务：**
    - 未完成任务：`- [ ] xxx`、`* [ ] xxx`、`+ [ ] xxx`、`1. [ ] xxx`，引用块中的任务同样识别。
    - 已完成任务（`- [x] xxx`）默认隐藏，可通过视图顶部按钮或设置项显示。
    - 代码块中的 `- [ ]` 不视为任务。
- **关键字：**
    - 支持 `TODO xxx`、`TODO: xxx`、`TODO：xxx`、`TODO - xxx`。
    - 支持注释形式：`// TODO xxx`、`# TODO xxx`、`/* TODO xxx */`、`<!-- TODO xxx -->`。
    - 支持括号形式：`【TODO】xxx`、`[TODO] xxx`。
    - 关键字在行尾时（如 `补充例句 TODO`），取关键字之前的文本作为正文。
    - 按整词匹配，`TODOS`、`todolist`、`mytodo` 不会被识别。
- **标签：**
    - `#todo xxx`、`#TODO xxx`、`#todo/子标签`，与 Obsidian 标签规则一致，始终不区分大小写。
    - 英文笔记中推荐使用标签写法，可避免正文中的普通单词 todo 被误识别。
- **不扫描的区域：**
    - 文件开头的 frontmatter 属性区。
    - 关闭「扫描代码块」时的代码块内容。

# 4、展示说明

- **单条 TODO：**
    - 主行格式为 `关键字：正文`，Markdown 任务显示为 `任务：正文`，右侧为行号（可关闭）。
    - 正文下方附带展示下一个非空行作为上下文；下一行是标题、代码块围栏或另一条 TODO 时不展示。
    - 开启自动换行时，超过折叠行数的长文本会被截断，点击「展开」查看全文；鼠标悬停可看到完整文本。
    - 图标区分来源：方框为任务、标签图标为 `#todo`、代码图标为代码块内的关键字。
- **平铺列表：** 按行号顺序展示，每条下方可展示所属标题路径（可关闭）。
- **按标题分组：**
    - 嵌套标题树：按标题层级逐级嵌套，每级显示其下（含子标题）的 TODO 总数，可逐级折叠。
    - 标题路径（单层）：每个完整标题路径一组，如「提成设置 > 复活」。
    - 第一个标题之前的 TODO 归入「（文档开头）」分组。
- **汇总范围：**
    - 当前文件：只展示正在查看的笔记。
    - 当前目录：汇总当前笔记所在目录下所有笔记的 TODO；开启「包含子目录」后递归汇总子目录。
    - 目录下 Markdown 文件数超过「目录扫描文件上限」时不扫描，并提示缩小范围。
- **目录范围的展示：**
    - 按标题分组：先按文件分组（文件名按自然顺序排列，如「2、xxx」在「10、xxx」之前），文件内再按标题分组。
    - 包含子目录时按目录树展示：每级子目录单独成为一个可折叠分组，显示该目录下（含所有子目录）的 TODO 总数；同一层先列子目录再列文件，均按名称自然排序。
    - 子目录分组以文件夹图标、加粗名称展示；文件分组以强调色文件图标、加粗名称与浅色 `.md` 后缀展示；标题分组按实际标题层级以浅色 `#`、`##`、`###` 等标记、常规字重展示；「（文档开头）」分组使用段落图标。
    - 平铺列表：按文件顺序、文件内按行号顺序平铺，每条下方展示「文件名 > 标题路径」。
    - 没有 TODO 的文件不展示，顶部显示 TODO 总数与文件数。
    - 点击 TODO 会打开对应文件并跳转到对应行。
- **快捷选择目录：**
    - 点击顶部摘要中的文件名或目录名，弹出树形目录选择框，默认选中当前展示的目录（文件范围下为当前文件所在目录）并展开其上级目录。
    - 点击目录行即选中该目录并切换为目录范围、锁定该目录；点击箭头只展开/折叠子目录。
    - 顶部搜索框按路径过滤目录，多个词用空格分隔，命中目录的上级目录自动展开。
    - 支持键盘操作：上下键移动、右键展开、左键折叠或跳到上级目录、回车确认。
    - 目录范围下，摘要右侧的目录树图标为「包含子目录」快捷开关，开启时高亮，与设置页中的同名配置同步；文件数超过扫描上限时，空状态中也提供「关闭包含子目录」入口。
    - 目录范围下，摘要右侧的向上箭头可一键切换并锁定上一级目录。
- **锁定目录：**
    - 目录范围下点击顶部摘要右侧的图钉图标，可锁定当前目录，之后切换到其他目录的笔记也不变；再次点击解除锁定。
    - 锁定状态随 Obsidian 布局保存，重启后仍然生效；锁定的目录被重命名或移动时自动跟随。
- **过滤：**
    - 视图顶部的输入框按关键词过滤 TODO，匹配关键字、正文、下一行与标题路径，目录范围下还匹配文件名。
    - 多个词用空格分隔，需全部命中；不区分大小写。
- **视图顶部按钮：** 与过滤输入框位于同一行，依次为当前文件/当前目录切换、平铺列表/按标题分组切换、全部展开/折叠、显示/隐藏已完成任务、刷新；侧边栏不显示标题栏时同样可见。
- **全部展开/折叠：** 按标题分组时可用，有任一分组展开时点击全部折叠（只保留最外层的子目录、文件或顶级标题），全部折叠后再次点击全部展开。
- **文本换行：**
    - 默认不自动换行，每条 TODO 与下一行上下文单行展示，超出部分通过整个列表的横向滚动查看。
    - 过滤框、按钮与顶部摘要固定在列表上方，列表区域独立滚动，横向滚动条贴在面板底部。
    - 在设置中开启「TODO 文本自动换行」后恢复换行展示，并按「长文本折叠行数」折叠长文本。
- **自动刷新：** 切换笔记、编辑笔记（停顿约 0.3 秒）、范围内的文件被新建、外部修改、重命名或删除时自动刷新；未变化的文件复用解析缓存。

# 5、配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 关键字 | `TODO` | 多个关键字用逗号分隔，如 `TODO, FIXME` |
| 区分大小写 | 开启 | 开启后只识别与关键字大小写一致的写法 |
| 识别标签 | 开启 | 识别 `#todo` 标签，不区分大小写 |
| 识别 Markdown 任务 | 开启 | 识别 `- [ ] xxx` 形式的任务 |
| 显示已完成任务 | 关闭 | 显示 `- [x] xxx` 形式的任务 |
| 扫描代码块 | 开启 | 识别代码块内注释形式的关键字 |
| 默认展示模式 | 平铺列表 | 平铺列表或按标题分组 |
| 展示行号 | 开启 | 在每条 TODO 右侧展示行号 |
| 平铺列表展示所属标题 | 开启 | 平铺列表模式下展示所属标题路径 |
| 分组样式 | 嵌套标题树 | 嵌套标题树或标题路径（单层） |
| 展示下一行 | 开启 | 附带展示下一个非空行 |
| TODO 文本自动换行 | 关闭 | 关闭时单行展示、整个列表横向滚动 |
| 长文本折叠行数 | 2 | 范围 1～10，开启自动换行时生效 |
| 默认范围 | 当前文件 | 当前文件或当前目录 |
| 包含子目录 | 关闭 | 目录范围下同时汇总子目录中的笔记 |
| 目录扫描文件上限 | 500 | 目录下 Markdown 文件数超过该值时不扫描 |

# 6、开发与安装

- **目录结构：**
    - `src/main.ts`：插件入口，注册视图、图标、命令、目录右键菜单与事件监听，负责目录汇总与解析缓存。
    - `src/view.ts`：侧边栏视图，负责范围切换、目录锁定、过滤、列表/分组渲染与跳转。
    - `src/folder-modal.ts`：目录选择弹窗。
    - `src/parser.ts`：TODO 解析器，逐行识别任务、关键字与标签。
    - `src/settings.ts`：设置页。
    - `src/types.ts`：公共类型、枚举与默认配置。
    - `test/parser.test.ts`：解析器测试用例。
- **常用命令：**
    - 安装依赖：`npm install`
    - 运行解析器测试：`npm test`
    - 开发模式（监听构建）：`npm run dev`
    - 构建：`npm run build`
- **启用插件：**
    - 将构建产物 `main.js`、`manifest.json`、`styles.css` 复制到 `<仓库>/.obsidian/plugins/current-file-todo/`。
    - 在「设置 → 第三方插件」中刷新已安装插件列表，启用「Current File TODO」。
    - 更新插件后，关闭再启用插件或重启 Obsidian 使改动生效。
